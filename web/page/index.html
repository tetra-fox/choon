choon

Checks that lossless audio is actually lossless.

A lossless file decoded from MP3, AAC, Opus or another lossy format keeps traces of its encoder: a frame grid or quantized band energies in the samples, and a cutoff in the spectrum. choon reads a file for them.

Source on GitHub

Available as a command-line tool or a Rust library

Command-line tool

cargo install choon

Checks directories of files in parallel, with exit codes and JSON for scripts.

Binaries for Linux, Windows and macOS Usage

Rust library

cargo add choon --no-default-features

Measures a file and reads it into a verdict, under thresholds the caller passes.
