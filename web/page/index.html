choon

Checks that lossless audio is actually lossless.

A FLAC or WAV file made from an MP3, AAC or Opus file keeps traces of the lossy encoder: its frame grid in the samples, its cutoff in the spectrum. choon reads a file for them.

Files stay on this device. The analysis runs in this tab and nothing is uploaded.

Drop audio files here

A file in a lossless format takes from several seconds to around a minute, depending on the device. Other files take far less. Files over are not read.

Readings

Kept in this browser under each file's name, until cleared.

    A reading says what the analyzer saw in the samples. The README says what each verdict means and what a reading cannot tell.
